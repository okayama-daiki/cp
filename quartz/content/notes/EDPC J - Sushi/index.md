興味深い遷移をする．式の両辺に`dp[i][j][k]`が出てくるが，移行してやれば何の問題もない．

皿は並び替えても問題ない
-> 寿司の個数によって分けてカウントしても問題ない．1個がi枚，2個がj枚，3個がk枚

`dp[i][j][k] := 置かれた寿司が1個，2個，3個の皿がそれぞれi枚，j枚, k枚の時の題意の期待値`

`dp[i][j][k]`
`= (dp[i][j + 1][k - 1] + 1) * k / n`
`+ (dp[i + 1][j - 1][k] + 1) * j / n`
`+ (dp[i - 1][j][k] + 1)     * i / n`
`+ (dp[i][j][k] + 1) * (1 - (i + j + k) / n)`
`= 1 + dp[i][j + 1][k - 1] * k / n + dp[i + 1][j - 1][k] * j / n + dp[i - 1][j][k] * i / n + dp[i][j][k] * (1 - (i + j + k) / n)`
(定数部分が消える)
`<=> dp[i][j][k] - dp[i][j][k] * (1 - (i + j + k) / n) = 1 + dp[i][j + 1][k - 1] * k / n + dp[i + 1][j - 1][k] * j / n + dp[i - 1][j][k] * i / n`
`<=> dp[i][j][k] * (i + j + k) / n = 1 + dp[i][j + 1][k - 1] * k / n + dp[i + 1][j - 1][k] * j / n + dp[i - 1][j][k] * i / n`
`<=> dp[i][j][k] = (1 + dp[i][j + 1][k - 1] * k / n + dp[i + 1][j - 1][k] * j / n + dp[i - 1][j][k] * i / n) * n / (i + j + k)`
`                = (n + dp[i][j + 1][k - 1] * k + dp[i + 1][j - 1][k] * j + dp[i - 1][j][k] * i) / (i + j + k)`

Base Caseは？
`dp[0][0][0] = 0`

```python
import sys
import functools

sys.setrecursionlimit(10**5)


@functools.lru_cache(maxsize=None)
def dp(i, j, k):
    if i == j == k == 0:
        return 0
    return (
        n
        + (dp(i, j + 1, k - 1) if k > 0 else 0) * k
        + (dp(i + 1, j - 1, k) if j > 0 else 0) * j
        + (dp(i - 1, j, k) if i > 0 else 0) * i
    ) / (i + j + k)


n = int(input())
a = list(map(int, input().split()))

sushi = [0] * 3
for e in a:
    sushi[e - 1] += 1

dp(*sushi)
```

#期待値DP #EDPC
[[hr.icon]]
以降は昔に書いたやつ

## 考え方

皿の番号は問題に影響を与えない．大事なのは皿にある寿司の個数．
つまり，x(1<x<=3)個の寿司がのった皿の個数がカウント出来ていれば良い．

## DPテーブル

`dp[i][j][k]` := 3個寿司がのった皿が`i`枚, 2個寿司がのった皿が`j`枚, 1個寿司が乗った皿が`k`枚からスタートした時，全ての寿司が無くなるまでサイコロを振った回数．

## 遷移

`dp[i][j][k] = ( dp[i-1][j+1][k] * i / n`                          <- 3個の皿
`              + dp[i][j-1][k+1] * j / n`                          <- 2個の皿
`              + dp[i][j][k-1] * k / n`                              <- 1個の皿
`              + dp[i][j][k] * (n - i - j - k) / n`      <- 0個の皿
`             ) + 1 `

サイコロを振っても寿司が減らないことがある → 自己辺があるのでDAGではない
上式では遷移が出来ない．

こういった場合は式変形を行えばよい．
左辺に`dp[i][j][k]`を集めると
`dp[i][j][k] - dp[i][j][k] * (n - i - j - k) / n = dp[i-1][j+1][k] * i / n`
`                                                + dp[i][j-1][k+1] * j / n`
`                                                + dp[i][j][k-1] * k / n`

`dp[i][j][k] * (1 - (n - i - j - k) / n)`
`= (dp[i-1][j+1][k] * i + dp[i][j-1][k+1] * j + dp[i][j][k-1] * k) / n`

`dp[i][j][k] * (i + j + k) / n`
`= (dp[i-1][j+1][k] * i + dp[i][j-1][k+1] * j + dp[i][j][k-1] * k) / n`

`dp[i][j][k]`
`= (dp[i-1][j+1][k] * i + dp[i][j-1][k+1] * j + dp[i][j][k-1] * k) / (i + j + k)`

---
ここで，`dp[i][j][k] * (n - i - j - k) / n`が「3個寿司がのった皿が`i`枚, 2個寿司がのった皿が`j`枚, 1個寿司が乗った皿が`k`枚の時，寿司がのった皿を引くまでに投げるサイコロの期待値」であることに着目すると，`dp[i][j][k] * (n - i - j - k) / n` = `n / (i + j + k)`と変形できる．

(例えば，コインで表が出る確率を1/3，裏が出る確率を2/3とすると，表が出るまでにコインを投げる回数の期待値は，1 * (1/3) + 2 * ( (1/3) * (2/3)^1) + 3 * ( (1/3) * (2/3)^2) + 4 * ( (1/3)*(2/3)^3) + ... = 1/3 + 4/9 + 12/27 + 32/81 + ... ≒ 2 )

Tips:: 幾何分布
確率pの試行を成功するまで繰り返すときに行う試行の回数は幾何分布に従う．期待値は1/p

上の条件では，寿司ののった皿を引く確率は`(i + j + k) / n` ．よって求めたい期待値は`n / (i + j + k)`となる．

これを踏まえると，遷移式は次のように変形できる．
`dp[i][j][k] =` (寿司がのった皿を引く場合の期待値) + (寿司がのっていない皿を引く場合の期待値)
