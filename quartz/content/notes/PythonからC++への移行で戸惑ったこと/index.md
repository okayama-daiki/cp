## 演算子の優先順位

Pythonの場合：シフト演算 >> ビット単位AND >> ビット単位XOR >> ビット単位OR >> 比較演算
C++ の場合：シフト演算 >> 比較演算 >> ビット単位AND >> ビット単位XOR >> ビット単位OR

- 例えば，`(bit >> shift_a) & 1 == 0`と`((bit >> shift_a) & 1) == 0`はPythonにおいて等価であるが，C++においては異なる

## 負の余り

Pythonの場合：`(-4) % 3 = 2`
C++の場合：`(-4) % 3 = -1`
